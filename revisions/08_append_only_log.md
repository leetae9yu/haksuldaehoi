## 3. 기술 개념의 평이화 및 법리적 가이드라인 준수 확인
1. **평이한 우리말 풀이 적용**:
   - **HTTP 요청**: 클라이언트가 웹서버에 데이터를 전송해 달라고 보내는 표준 통신 신호
   - **대기열(queue)**: 방문할 웹 주소의 목록을 순차적으로 관리하는 작업 목록
   - **렌더링**: 웹 코드를 실행하여 이용자에게 보이는 화면을 실제로 그려내는 과정
   - **정규화**: 수집된 비정형 데이터를 통일된 텍스트 구조로 정돈하는 전처리
   - **식별자(User-Agent)**: 수집 프로그램이 요청 헤더를 통해 자신의 명칭과 속성을 서버에 스스로 알리는 통신 표식
   - **토큰**: 모델이 텍스트를 수치적으로 처리하기 위해 분할하는 기본 단위
   - **매개변수**: 대규모 데이터의 학습 결과를 수치로 저장하는 모델 내부의 연산 변수
2. **금지 기술 용어 미도입**: 임베딩(embeddings), 벡터(vectors), 손실함수(loss functions), 역전파(backpropagation), 트랜스포머(Transformer), 어텐션(attention), RAG 등 새로운 공학적 개념을 일체 도입하지 않음.
3. **법적 왜곡 방지 가이드라인 준수**:
   - robots.txt를 '단순한 임의적 권고'로 단정하지 않고 프로토콜 지침으로 설명함.
   - User-Agent가 운영자의 '실제 신원을 증명'한다고 주장하지 않고 자체 통신 표식으로 정확히 규정함.
   - 토큰을 '의미론적 최소 단위'로 단정하지 않고 수치 연산을 위한 분할 단위로 규정함.
   - 매개변수를 '단어 간 연결 강도'로 축약하지 않고 모델 내부의 연산 변수로 정확히 기술함.
