# 팀이 결정해야 할 쟁점

## 논문의 대상과 범위

1. 보호하려는 성과는 웹사이트 운영자의 원천 콘텐츠·데이터베이스인가, AI 개발사가 만든 학습용 데이터셋인가?
2. 제목의 “무단”은 단순 무허가를 뜻하는가, 명시적 거부나 기술적 통제를 우회한 수집을 뜻하는가?
3. 논문의 대상은 텍스트 기반 생성형 AI인가, 이미지·음성·영상 모델까지 포함하는가?
4. 크롤링, 데이터셋 구축, 전처리, 학습의 행위 주체가 다른 경우 책임을 어디까지 다룰 것인가?

## (파)목 판단구조

5. 기술적 통제 우회와 라이선싱 시장 침해는 각각 어떤 법정 요건에 대응하는가?
6. 두 표지가 모두 필요한가, 하나가 강하면 다른 하나가 약해도 되는가, 아니면 다른 사실과 함께 종합하는가?
7. robots.txt 위반은 독립적인 위법성 표지인가, 거부 의사와 수집자의 인식을 보여주는 보조사실인가?
8. 직접 경쟁관계가 없어도 경제적 이익 침해를 인정할 수 있다면 그 한계는 무엇인가?
9. 실제 라이선스 계약, 라이선스 상품, 협상 이력, 동종 거래 중 무엇을 최소 증명자료로 요구할 것인가?
10. 권리자의 일방적인 유료화 의사만으로 라이선스 시장을 인정하는 순환논증을 어떻게 막을 것인가?

## 다른 법률과의 관계

11. 저작권법상 공정이용 또는 향후 TDM 면책 대상인 이용을 (파)목으로 다시 위법화하려면 어떤 추가 사정이 필요한가?
12. (파)목을 보충적으로 적용하면서 공개정보의 자유 이용 영역을 어떻게 보존할 것인가?

## ROSS 판결

13. 비생성형 법률 검색 도구이자 직접 경쟁 제품인 ROSS와 일반 생성형 AI 학습을 어디까지 비교할 수 있는가?
14. 저작권법상 시장 영향 판단을 (파)목의 경제적 이익 침해로 옮길 때 필요한 중간 논리는 무엇인가?
15. 항소심에서 지방법원 판단이 변경될 가능성을 각주와 본문에 어떻게 표시할 것인가?

## 실무적 유용성

16. 원고와 피고가 각각 어떤 사실과 증거를 제출해야 하는가?
17. 금지청구와 손해배상에서 요구되는 증명 수준을 구별할 것인가?
18. 논문이 제시하는 판단 표지는 법원이 적용할 체크리스트인가, 학설적 해석 방향인가?
