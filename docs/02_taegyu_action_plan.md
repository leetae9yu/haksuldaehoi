# 태규 작업 계획

## 가장 먼저 할 일

### 1. 서론

- 문단 `[23]`에서 연구 질문과 “무단”의 의미를 정의한다.
- 문단 `[25]`에서 선행연구가 해결하지 못한 공백을 제시한다.
- 문단 `[27]`의 장별 안내를 실제 목차와 일치시킨다.
  - 판례·학설 검토는 IV장이다.
  - 행위 중심 해석론과 ROSS 분석은 V장이다.
- 논문의 차별점을 한 문단으로 명시한다.

완료 기준: 서론만 읽어도 독자가 연구 질문, 핵심 주장, 기존 논의와의 차이, 연구 방법을 각각 한 문장으로 답할 수 있어야 한다.

### 2. 제2장 기술 설명

- `section_II_final.md`를 출발점으로 사용한다.
- 크롤링, 데이터셋 구축, 전처리, 학습을 서로 다른 단계로 유지한다.
- `robots.txt`와 실제 접근통제를 구별한다.
- Cloudflare 통계로 절대 트래픽 증가나 서버 부담까지 증명하지 않는다.
- 검색 크롤링과 학습 크롤링을 지나치게 이분법적으로 설명하지 않는다.
- 반복되는 `robots.txt` 설명과 저작권 논의를 줄인다.
- 장 마지막을 III장의 부정경쟁방지법 검토로 연결한다.

완료 기준: 모든 기술 설명 문단이 뒤의 법적 판단 표지 중 하나와 연결되거나, 필수 배경으로서 명확한 기능을 가져야 한다.

### 3. 결론

현재 문단 `[178]` 하나를 다음 네 문단으로 나눈다.

1. 연구 결과
2. 과잉보호를 막는 제한 기준
3. 실무적 유용성
4. 연구의 한계와 후속 과제

완료 기준: 결론에 새 논증을 추가하지 않고 본론의 결과, 적용 한계, 당사자의 증명사항, 후속 과제만 정리해야 한다.

### 4. ROSS 부분

- 표 3을 본문 문단으로 풀어 쓴다.
- ROSS가 생성형 AI 사건이 아니라 비생성형 법률 검색 모델 사건임을 명시한다.
- 저작권법상 공정이용 판단과 국내 부정경쟁방지법 (파)목을 직접 동일시하지 않는다.
- 2025년 지방법원 판단이 항소 중이라는 절차 상태를 반영한다.

### 5. 공동 교정

- 각주 본문과 참고문헌 목록의 일대일 대응
- 중복 URL과 이중 마침표
- 판결·결정 표기
- 학술지·권·호·발행기관·연도·면수 형식
- 제목과 본문 용어 통일
