# haksuldaehoi

생성형 AI 학습을 위한 무단 데이터 크롤링과 부정경쟁방지법상 규율에 관한 논문 수정 작업 저장소입니다.

## 원칙

- `본논문_1차.hwpx`는 피드백 당시의 원본입니다. 직접 수정하지 않습니다.
- 검토 결과와 수정 제안은 `docs/`에 별도로 기록합니다.
- HWPX 본문 문단 번호는 분석 과정에서 XML의 본문 문단을 순서대로 추출해 부여한 번호입니다. HWPX 화면의 쪽·줄 번호와는 다릅니다.
- 제안 문장은 바로 붙여 넣기보다 팀의 최종 논증 방향과 인용 근거를 확인한 뒤 반영합니다.

## 파일 안내

- `본논문_1차.hwpx`: 원본 논문
- `section_II_draft.md`: 제2장 초기 초안
- `section_II_final.md`: 제2장 별도 수정안
- `docs/01_feedback_and_roles.md`: 받은 피드백과 역할 분담
- `docs/02_taegyu_action_plan.md`: 태규 작업 순서와 완료 기준
- `docs/03_sentences_to_add.md`: 추가할 문장 초안
- `docs/04_sentences_to_polish.md`: 윤문할 문장과 수정안
- `docs/05_cuts_and_merges.md`: 삭제·병합·이동 후보
- `docs/06_questions_to_decide.md`: 팀이 결정해야 할 쟁점
- `docs/07_citation_and_bibliography_audit.md`: 각주·참고문헌 점검
- `docs/08_ross_case_caution.md`: ROSS 판결 활용 시 주의점

## 태규의 우선순위

1. 서론의 연구 질문·기여점·목차 안내 수정
2. 제2장 기술 설명을 `section_II_final.md` 중심으로 압축·정확화
3. 결론을 연구결과·제한기준·실무적 유용성·한계의 네 문단으로 재구성
4. ROSS 판결을 직접 적용 근거가 아닌 제한적인 비교법 자료로 수정
5. 세영·아림과 각주·참고문헌·오타·문장 연결성 전수 점검
